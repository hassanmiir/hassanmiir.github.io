PART 1

What is a variable?

A named box where your program keeps a piece of data.

A box with a name and a value
Declare it, then use it anywhere
Your first variable — live!
The Big Idea

A variable is a labelled box

Think of the computer's memory as a wall of boxes. A variable is one box that:

Has a name

So you can find it again — like age or gpa.

Holds a value

The data inside — like 20 or 3.75.

Can change

That's why it's "variable" — the value can vary.

age → [ 20 ]

Syntax

How to make one

int age = 20;

int

The type — what kind of data (a whole number).

age

The name — how you refer to the box.

= 20

The value — what goes inside.

Read it as"Make an integer box called age, and put 20 in it."
Using It

Once it has a name, use it anywhere

int age = 20;
cout << "You are " << age << " years old." << endl;
age = 21;                       // change the value
cout << "Next year: " << age << endl;
OutputYou are 20 years old.
Next year: 21

Counts: credits, year of study, number of students.

Use double for…

Measurements: GPA, average mark, money.

char

A single letter or symbol. Single quotes: 'A', not "A".

bool

A yes/no switch. Perfect for "is the student enrolled?"

PART 3

Storing text

Names, titles, feedback — a Portal is full of text.

A word in a char[] box
std::string — the better way
Store a student's name — live
Text

A word fits in a char[] box

char name[40] = "Sara";
cout << "Student: " << name << endl;

A char[40] is a box that holds up to 40 characters — enough for a name. The [40] is the maximum size.

OutputStudent: Sara
The Better Way

Meet std::string

#include <string>              // needed for string
using namespace std;

string name = "Sara Khan";     // holds a whole name, any length
string course = "Software Engineering";

Any length

No fixed [40] — it grows to fit the text.

Easy to use

Join, compare, and measure text simply. We'll go deep in Lecture 8.

In classThe quick in-slide runner uses char[]; in your full compiler (OnlineGDB) use string — that's what our project will use.

PART 4

Asking the user

A Portal is only useful if real people can enter their data.

Read input with cin >>
cout sends out, cin brings in
A live registration form
Input

Read input with cin

int age;
cout << "Enter your age: ";
cin >> age;                      // store what they type into age
cout << "You are " << age << endl;

cout <<

Arrows point OUT — send to the screen.

cin >>

Arrows point IN — read into a variable.

Input

Read several values at once

char name[40];
int  year;
cout << "Name and year of study: ";
cin >> name >> year;
cout << name << " is in year " << year << endl;

Chain >> to read several things in order. The user types them separated by spaces.

PART 5

Rules & good habits

A few things that save you from bugs.

Match the type to the data
Name variables clearly
const — values that never change
Watch Out

The whole-number trap

int total = 7;
int count = 2;
cout << total / count << endl;     // prints 3, not 3.5 !
Why?Two ints divide as whole numbers — the .5 is thrown away. For an average GPA, use double.

Fix: make at least one a double → 7.0 / 2 gives 3.5.

Good Habits

Clear names & const

Name for meaning

gpa and yearOfStudy beat x and y. Future-you will thank you.

const = never changes

const int PASS_MARK = 50; — a value fixed for the whole program.

In our projectThings like the pass mark or max credits are const — set once, used everywhere.

One Solution Compare yours

How the record works

double average = (mark1 + mark2) / 2.0;  // decimals kept
bool passed = average >= 50;

cout << "==== STUDENT RECORD ====" << endl;
cout << "Name:    " << name << endl;
cout << "Number:  " << number << endl;
cout << "Year:    " << year << endl;
cout << "Average: " << average << endl;
cout << "========================" << endl;

/ 2.0 keeps decimals

80 and 60 average to 70.0, not 70 by luck.

bool passed

A comparison gives true/false — the seed of decisions (Lecture 4).

That's a real record
