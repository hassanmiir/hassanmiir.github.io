The Student Study Buddy

A console program a student would actually use — to track subjects, log study hours, record grades, and see how they're doing.

The idea

Your group will build a menu-driven C++ program that helps a student stay organized. It runs in the terminal, remembers data while it's open, and (by the final lecture) saves everything to a file so nothing is lost between runs.

Who is it for? Imagine a first-year student who wants one simple place to track what they're studying and how they're progressing. You are building that tool for them.

What it should do

📚 Manage subjects

Add a subject, list all subjects, remove one.

⏱️ Log study hours

Record hours studied for a subject and total them up.

📝 Record grades

Store grades per subject and compute an average.

📊 Progress summary

Show a clear report: total hours, average grade, strongest subject.

💾 Save & load

Write everything to a file and read it back next time.

🧭 Simple menu

A numbered menu loop the user picks from until they quit.

How it grows with the course

You don't build this all at once. Each lecture gives you the piece you need next:

Stretch goals

  • Warn when a subject has fewer than 2 study hours this week.
  • Sort subjects from highest to lowest grade.
  • Add a "study streak" counter.
  • Let the user edit or delete a past entry.

How you'll be graded

  • It works (40%) — compiles and runs without crashing; the menu behaves.
  • Correctness (25%) — totals, averages, and the summary are right.
  • Structure (20%) — clear functions, sensible names, comments.
  • File save/load (10%) — data survives between runs.
  • Polish & stretch (5%) — friendly output, a stretch goal attempted.
Deliverable. One .cpp file (or a small set of files), a short README explaining how to compile and run it, and a 3-minute demo in the final session.

Teamwork

Work in small groups. Suggested roles that rotate each week: Driver (types the code), Navigator (reads the brief and checks logic), Tester (tries to break it and reports bugs). Everyone should write code across the ten weeks.
