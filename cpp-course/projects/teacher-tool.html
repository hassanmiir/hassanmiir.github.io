The Teacher Gradebook

A console program a teacher would use to manage a class — add students, record scores, see class statistics, and keep the gradebook saved in a file.

The idea

Your group will build a menu-driven C++ program that helps a teacher run a class. It stores a list of students and their scores, calculates useful statistics, and saves the gradebook so it's there the next day.

Who is it for? Picture a teacher with 25 students and a stack of test scores. They want totals, averages, and a quick view of who is doing well and who needs help — without a spreadsheet.

What it should do

👩‍🎓 Manage students

Add a student, list the class, remove a student.

✅ Record scores

Enter a test score for a student; store several per student.

📊 Class statistics

Class average, highest and lowest score, pass/fail count.

🏆 Top & struggling

Show the top student and flag anyone below a threshold.

💾 Save & load

Persist the whole gradebook to a file and reload it.

🧭 Simple menu

A numbered menu the teacher picks from until they quit.

Build it one lecture at a time — each new topic unlocks the next feature:

Stretch goals

  • Compute each student's own average across several tests.
  • Sort the class list by average, highest first.
  • Export a simple report to a separate text file.
  • Let the teacher set the passing threshold at startup.

How you'll be graded

  • It works (40%) — compiles and runs without crashing; the menu behaves.
  • Correctness (25%) — averages, min/max, and pass/fail counts are right.
  • Structure (20%) — clear functions, sensible names, comments.
  • File save/load (10%) — the gradebook survives between runs.
  • Polish & stretch (5%) — neat tables, a stretch goal attempted.
Deliverable. One .cpp file (or a small set of files), a short README with compile/run instructions, and a 3-minute demo in the final session.

Teamwork

Work in small groups with rotating roles: Driver (types the code), Navigator (reads the brief, checks logic), Tester (tries to break it, reports bugs). Everyone writes code across the ten weeks.
