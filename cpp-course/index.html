How to use this site

Everything runs in the browser — no install needed to view.

📱 Scan to open

Scan the QR code shown in class to jump straight to today's lecture on your phone or laptop.

⌨️ Navigate slides

Use arrow keys, or swipe on touch. Press S for speaker notes, F for fullscreen, Esc for an overview.

💻 Try the code

Use any C++ compiler, or an online one like godbolt.org or onlinegdb.com to run the examples.
